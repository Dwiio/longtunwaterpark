## ✨ Fitur Utama

- **Halaman Utama (`index.html`)**: Menyajikan informasi umum, jam operasional, lokasi, dan daya tarik utama waterpark.
- **Halaman Fasilitas (`fasilitas.html`)**: Menampilkan katalog lengkap wahana seperti Kolam Arus, Beragam Seluncuran, area bilas, dan wahana bermain anak.
- **Tampilan Responsif**: Desain yang menyesuaikan secara otomatis untuk layar desktop, tablet, dan smartphone dengan visual yang menarik.
- **Interaktivitas JavaScript (`main.js`)**: Navigasi menu responsif, galeri/pop-up, dan efek visual interaktif.
- **Konfigurasi Multi-Platform**: Siap di-deploy secara langsung ke Netlify maupun Vercel.
